# Multi-Pick Similarity Uses Field-Level Max-Match with Exclusion Suppression

Multi-pick Similarity Queries rasterize Inclusion and Exclusion Picked Features onto discrete Embedding Lattice Patches and score every lattice Patch by its maximum cosine similarity to any Included Patch minus a weighted maximum positive cosine similarity to any Excluded Patch ($S(x) = \max_{p \in P^+} \cos(x, p) - \alpha \max_{n \in P^-} \max(0, \cos(x, n))$, with Exclusion winning on shared-patch collisions). Averaging Included Patch vectors into a single Rocchio centroid was rejected because geophysical polylines and polygons (such as faults cutting multiple strata or multi-facies geobodies) span heterogeneous latent directions whose mean collapses local character rather than matching each constituent facies.
